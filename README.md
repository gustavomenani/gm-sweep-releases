# GM Sweep — downloads

Este repositório guarda só os instaladores do GM Sweep e o manifesto de atualização (`latest.json`). O código-fonte
não fica aqui.

Baixe a versão mais nova em **Releases**. Cada release traz o SHA-256 dos arquivos e o link do relatório do
VirusTotal: confira antes de instalar.

O app atualiza sozinho a partir daqui. O manifesto é assinado, e o app só instala o que bate com essa assinatura e
com o SHA-256 que ela promete.
