# GM Sweep — downloads

English · [Português](#português)

GM Sweep is a cleanup and optimization app for Windows 11 that says exactly what it does. It speaks English,
Portuguese, Spanish, German, French and Italian.

This repository holds only the GM Sweep installers and the update manifest (`latest.json`). The source code is not
kept here.

Download the newest version from **Releases**. GitHub shows the SHA-256 of each file next to it, and the release
notes link to the VirusTotal report when the release has one: check them before installing.

The app updates itself from here. The manifest is signed, and the app only installs what matches that signature and
the SHA-256 it promises.
